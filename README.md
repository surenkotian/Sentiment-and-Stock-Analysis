# Stock Sentiment Analysis - Candlestick Feature

## Overview
This branch introduces a new feature for analyzing stock sentiment using candlestick patterns. The feature processes historical stock data, generates candlestick charts, and integrates sentiment analysis from financial news.

## Features
- **Candlestick Pattern Detection**: A new module that identifies candlestick patterns in stock price data.
- **Sentiment Analysis**: Integration of sentiment analysis to assess market sentiment based on news and historical data.
